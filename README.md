### Resumen

El presente Trabajo de Fin de Grado tiene como objetivo el desarrollo
e implementación de un plugin para Unreal Engine 5 (UE5) que facilite la
creación de sistemas planetarios personalizados. Este plugin busca aprovechar las herramientas de generación procedimental y simulación avanzada
del motor, ofreciendo un entorno modular y flexible para diseñar planetas y
cuerpos celestes completamente configurables.

This Bachelor's Thesis aims to develop and implement a plugin for Unreal Engine 5 (UE5)
that facilitates the creation of custom planetary systems. This plugin seeks to leverage the engine's
procedural generation and advanced simulation tools, offering a modular and flexible environment for
designing fully configurable planets and celestial bodies.

Instrucciones de uso:

Para ampliar funcionalidades del plugin, crea una carpeta Plugins en la raíz de tu proyecto c++ y clona este repositorio dentro.
Haz también click derecho en el .uproject de tu proyecto y dale a Generate Visual Studio project files.

To expand the plugin's functionality, create a Plugins folder in the root of your C++ project and clone this repository into it.
Also, right-click on your project's .uproject file and select Generate Visual Studio project files.
